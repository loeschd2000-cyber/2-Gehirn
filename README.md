# Zweites Gehirn

- `index.html` – die App (läuft über GitHub Pages im Browser)
- `android/` – die Android-App mit „Hey Jarvis“ im Hintergrund
- `.github/workflows/android.yml` – baut die Android-App automatisch bei jeder Änderung

Download der Android-App: unter **Releases** → „Zweites Gehirn – Android-App“ → `ZweitesGehirn.apk`.

Das Aktivierungswort „Hey Jarvis“ nutzt die freien Modelle von [openWakeWord](https://github.com/dscripka/openWakeWord) (Apache-2.0).
